# Subscription Hunter

**Охотник за подписками: находит забытые автосписания в банковской выписке и подсказывает, как их отменить.**

Пробный период за 1 ₽, который тихо превратился в 399 ₽ в месяц. Онлайн-кинотеатр, который вы не открывали с весны. Сервис, который поднял цену на треть, а вы не заметили. Subscription Hunter читает выписку из вашего банка и за секунду показывает, сколько на самом деле уходит на подписки — в месяц и в год.

**Выписка не покидает ваш компьютер.** Скрипт работает без интернета и без сторонних библиотек: никаких серверов, аккаунтов и «дайте доступ к банку».

```
$ python3 subhunter.py выписка.csv

# Активных подписок: 5 · ≈ 5 837 ₽ в месяц · ≈ 70 044 ₽ в год

| Подписка          | Период | Сумма   | В год    | Заметки                                       |
|-------------------|--------|---------|----------|-----------------------------------------------|
| FITNESS PRIME     | месяц  | 2 900 ₽ | 34 800 ₽ | —                                             |
| ChatGPT Plus      | месяц  | 1 990 ₽ | 23 880 ₽ | —                                             |
| Яндекс Плюс       | месяц  | 399 ₽   | 4 788 ₽  | цена выросла на 33%: было 299 ₽, стало 399 ₽  |
| Okko              | месяц  | 399 ₽   | 4 788 ₽  | началась с пробного периода за 1 ₽            |
| Apple             | месяц  | 149 ₽   | 1 788 ₽  | отменять в настройках iPhone, а не в банке    |
| Иви (отменена?)   | месяц  | 399 ₽   | 4 788 ₽  | списаний нет с 15.06.2026                     |
```

Полный отчёт на вымышленной выписке — в [`examples/otchet-primer.md`](examples/otchet-primer.md).

## Что находит

- **Все регулярные списания** — раз в неделю, месяц, квартал, полгода или год. Даже если подписки нет в справочнике: фитнес-клуб, онлайн-школа, сервис с непонятным названием в выписке.
- **Пробные периоды**, которые стали платными.
- **Подорожание** — на сколько процентов и с какой суммы.
- **Уже отменённые** подписки — чтобы не искать то, что вы и так отключили.
- **Подписки через App Store и Google Play** — их нельзя отменить в банке или в самом сервисе, и отчёт об этом предупреждает.
- **Где отменять** каждую подписку и что делать, если деньги списали после отмены — со шаблоном заявления на возврат по ст. 32 Закона «О защите прав потребителей».

Обычные покупки — продукты, кофе, такси — в отчёт не попадают, даже если они каждую неделю.

## Быстрый старт

Нужен только Python 3.9 или новее — на Mac и Linux он обычно уже есть.

1. Выгрузите выписку по карте в формате **CSV** из приложения или интернет-банка — лучше за 3–6 месяцев.
2. Запустите:

```bash
git clone https://github.com/gregreshetnyak52-crypto/subscription-hunter
cd subscription-hunter
python3 skills/subscription-hunter/scripts/subhunter.py ~/Downloads/выписка.csv
```

Несколько карт или банков — перечислите файлы через пробел. Отчёт в таблицу: `--format csv -o подписки.csv`, в JSON: `--format json`.

Колонки выписки определяются автоматически: дата операции, описание, сумма (или отдельно «расход» и «приход»), статус. Кодировка (UTF-8 или Windows-1251) и разделитель (`;`, `,`, табуляция) — тоже. Если ваш банк выгружает выписку так, что скрипт её не читает, — [создайте issue](../../issues/new) с заголовками колонок (без самих операций).

## С ИИ-агентом: Claude Code, Codex, Cursor

Скилл `subscription-hunter` делает то же самое, но в разговоре: запускает поиск, уточняет спорные случаи («это аренда или подписка?»), помогает отменить и пишет заявление на возврат.

**Claude Code** — в обычном терминале:

```bash
claude plugin marketplace add gregreshetnyak52-crypto/subscription-hunter
claude plugin install subscription-hunter@subscription-hunter
```

**Codex или Cursor:**

```bash
git clone https://github.com/gregreshetnyak52-crypto/subscription-hunter
cd subscription-hunter && sh install.sh codex    # или cursor
```

Потом попросите агента: «Найди мои подписки в выписке выписка.csv».

## Как это работает

1. Списания группируются по продавцу: из описания убираются номера терминалов, города и служебные слова. Известные сервисы распознаются по [справочнику](skills/subscription-hunter/scripts/services.json).
2. Для каждой группы проверяется, повторяются ли списания через равные промежутки — неделя, месяц, квартал, полгода, год. Пропущенный месяц не мешает.
3. Суммы должны быть похожи (±30%), иначе это обычные покупки у одного продавца.
4. Подписка считается отменённой, если очередного списания нет дольше, чем период плюс запас.

## Ограничения

- Нужна выписка в CSV. PDF и Excel пока не читаются — их можно выгрузить заново в CSV или попросить ИИ-агента перевести таблицу.
- Годовую подписку видно только по двум списаниям, то есть по выписке больше чем за год. По одному списанию известного сервиса она попадает в «Возможные подписки».
- Регулярные платежи вроде аренды, кредита или мобильной связи тоже попадут в отчёт — решать, что из этого подписка, вам.
